# FitClub — система управління фітнес-клубом

Курсова робота з дисципліни «Документування програмного забезпечення та шаблони проектування» (Проєкт 14).
Веб-застосунок автоматизує роботу фітнес-клубу: облік клієнтів і абонементів, реєстрацію відвідувань,
керування тренерами й розкладом, запис на заняття, автоматичні сповіщення та звіти.

## Основні функції
| Функція |
|---|
| Облік клієнтів: ПІБ, вік, телефон, абонемент, термін дії абонемента |
| Відстеження відвідувань: кожен прихід клієнта (check-in) реєструється в базі даних |
| Управління тренерами: профіль зі спеціалізацією, графіком роботи і списком клієнтів |
| Запис на групові тренування та індивідуальні заняття |
| Тарифні плани: разове відвідування, абонемент на місяць, на рік, на N відвідувань; додаткові опції |
| Автоматичне повідомлення клієнтів про закінчення терміну дії абонемента |

**Звіти:** активність відвідувань клієнтів, доходи клубу за місяць / рік,
завантаженість тренерів і залів по днях.

## Ролі користувачів
| Роль | Можливості |
|---|---|
| Гість | Перегляд тарифів, розкладу і тренерів, реєстрація |
| Клієнт | Купівля абонемента, запис на заняття та скасування, історія відвідувань, сповіщення |
| Тренер | Власний графік роботи, список своїх клієнтів і записів |
| Адміністратор рецепції | Реєстрація відвідувань, облік клієнтів, оформлення абонементів |
| Адміністратор клубу | Керування тренерами, залами, розкладом, тарифами й налаштуваннями; звіти |

## Технологічний стек
- **Backend:** Python 3.12, FastAPI, SQLAlchemy 2, Alembic, Pydantic v2, JWT, APScheduler
- **База даних:** PostgreSQL (Docker Compose)
- **Frontend:** React (JavaScript, Vite), React Router, Axios, Recharts
- **Якість коду:** ruff, ESLint, Prettier

## Архітектура
Шарова архітектура бекенду: REST-роутери → сервіси → доменна модель → репозиторії → БД.
Бізнес-логіка побудована на GoF-шаблонах (Factory Method, State, Decorator, Strategy, Facade,
Chain of Responsibility, Command, Observer та інші), принципах SOLID і GRASP.
